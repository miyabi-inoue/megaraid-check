# Security Policy

## Supported Versions

Currently, only the latest release of megaraid-check is supported.

## Reporting a Vulnerability

If you discover a security vulnerability, please do not report it in a public GitHub issue.

Please report it privately using GitHub's private vulnerability reporting feature, if available.

When reporting a vulnerability, please include:

- A description of the issue
- Steps to reproduce it
- The affected version
- Any relevant logs or configuration details

Please remove or mask sensitive information such as hostnames, disk serial numbers, WWNs, email addresses, and other environment-specific data.
